# Indicator Lab Interactive — 技术指标交互式计算器 设计文档

## 一、产品定位

一款纯前端 HTML 工具，用户选择股票后可交互式调整四个技术指标的参数，所有图表实时重绘。用于教学演示和指标行为探索。

## 二、用户场景

1. 在顶部下拉框选择一支股票（5 只可选）
2. 左侧面板展开四个指标的参数控件
3. 拖拽 RSI 周期滑块 → RSI 曲线与超买超卖线实时刷新
4. 修改布林带倍数 → 轨道宽度变化，价格穿透点高亮
5. 所有指标联动更新，无需刷新页面
6. 底部指标卡显示各指标最新值

## 三、技术架构

```
指标计算 (纯 JS)          数据层              渲染层
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ RSI(N)       │    │ 股票 OHLCV   │    │ Chart.js     │
│ MACD(f,s,g)  │───▶│ 数据内联 JS  │───▶│ 4 个子图     │
│ BOLL(N,K)    │    │ (5只股票)    │    │ 响应式布局   │
│ ATR(N)       │    │              │    │ 颜色体系     │
└──────────────┘    └──────────────┘    └──────────────┘
```

**关键设计决策**

| 决策 | 选择 | 原因 |
|------|------|------|
| 计算位置 | 浏览器端 JS | 参数实时调整，不可能每次都调 Python |
| 数据加载 | `<script>` 内联 | file:// 协议不支持 fetch() |
| 图表库 | Chart.js (本地) | 下载到 vendor/，离线可用 |
| 布局 | CSS Grid | 响应式，无外部依赖 |
| 参数持久化 | URL hash | 刷新页面保持参数，可分享 |

## 五、功能规格

### 5.1 股票选择

- 下拉框切换 5 只股票：中芯国际 A / 比亚迪 A / 长江电力 A / 中芯国际 HK / 比亚迪 HK
- 切换时所有图表和指标卡同步刷新
- 显示股票名称 + 代码 + 最新收盘价 + 涨跌幅

### 5.2 四个指标面板

每个指标一个独立控制区域，包含：

**RSI — 相对强弱指标**
- 参数：周期 N（范围 2-50，默认 14，步长 1）
- 显示：RSI 折线图 + 70/30 参考线 + 超买超卖区域填充
- 指标卡：最新 RSI 值 + 状态标签（超买/中性/超卖）

**MACD — 指数平滑异同移动平均线**
- 参数：快线 Fast（范围 2-50，默认 12）、慢线 Slow（范围 Fast+1-100，默认 26）、信号线 Signal（范围 2-30，默认 9）
- 显示：DIF 线 + DEA 线 + MACD 柱状图（红涨绿跌）
- 指标卡：最新 DIF、DEA、MACD 柱值 + 金叉/死叉提示

**布林带 — Bollinger Bands**
- 参数：周期 N（范围 5-100，默认 20）、倍数 K（范围 1.0-4.0，默认 2.0，步长 0.1）
- 显示：价格 K 线 + 上中下三条轨道 + 轨道区域半透明填充
- 指标卡：中轨/上轨/下轨值 + 带宽百分比

**ATR — 平均真实波幅**
- 参数：周期 N（范围 2-50，默认 14）
- 显示：ATR 绝对值折线 + ATR% 折线（双 Y 轴）
- 指标卡：最新 ATR + ATR% + 波动等级

### 5.3 主价格图

- 叠加 MA 均线（可开关）：MA5 / MA10 / MA20 / MA60
- 叠加布林带通道
- 时间范围缩放（最近 1 月 / 3 月 / 6 月 / 1 年 / 全部）

### 5.4 交互行为

- 参数变更后 200ms debounce 再重算重绘
- 图表支持鼠标悬停查看数值
- URL hash 记录当前股票和参数，可复制分享
